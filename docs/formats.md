# Формати файлів Darkest Hour

Статус: ✅ підтверджено на реальних файлах · 🟡 відомо з документації HoI2/спільноти, ще не звірено · ❓ невідомо

## Загальне
- 🟡 Текст у **Windows-1252**. Деякі файли модів перезбережені як UTF-8 з BOM — `dh-text` це розпізнає.
- 🟡 Шляхи всередині файлів у стилі Windows (`\`, довільний регістр) → `dh-vfs`.

## Paradox script (`*.txt`, `*.eug`, `*.inc`, сейви)
- 🟡 `ключ = значення`, `ключ = { ... }`, голі списки `{ 1 2 3 }`, рядки в `"..."` без екранування,
  коментарі `#` до кінця рядка, булеві `yes`/`no`. Ключі нечутливі до регістру.
- 🟡 Оператори `<`, `>` у тригерах (парсер також приймає `<=`/`>=`).
- 🟡 Дати блоком: `{ year = 1936 month = january day = 0 hour = 0 }`. Припущення: `day` (і числовий `month`)
  нумеруються з **нуля**. Потрібно перевірити на стартовій даті сценарію 1936 (`GameDate::from_block`).

## Сценарії (`scenarios/*.eug`)
- 🟡 `header = { name startdate selectable = { TAG ... } }`
- 🟡 `include = "шлях"` — підставляє вміст файлу; шлях відносно кореня гри (запасний варіант — відносно поточного файлу).
- 🟡 `country = { tag capital ownedprovinces controlledprovinces nationalprovinces ... }`

## CSV (`db/*.csv`, `config/*.csv`)
- 🟡 Роздільник `;`, без лапок, рядки-коментарі з `#`.
- 🟡 Локалізація: `КЛЮЧ;English;French;German;Polish;Spanish;Italian;...;X`, `X` — маркер кінця запису.
- 🟡 `db/province.csv` має рядок заголовків; зараз інтерпретуються лише `Id` і `Name`, решта колонок зберігається як є.

## Карта (`map/`)
- ❓ `id.tbl`, `boundbox.tbl`, `light*.tbl` — бінарні, публічної специфікації не знайдено. План: `dh-tool probe`
  (ентропія, кандидати розміру записів, заголовкові u32), потім перевірка гіпотез у Ghidra на коді завантаження карти.
- 🟡 `colorscales.csv` — градієнти кольорів провінцій (індекси 0–64).

## Графіка й звук
- 🟡 Інтерфейс — BMP (напр. `gfx/interface/ill_prov_<id>.bmp`). Решта ❓.
