# Специфікації форматів (з HoI2Editor)

Описи форматів файлів Darkest Hour, витягнуті з коду "Alternative HoI2 Editor" (C#).
Код редактора не копіюється: це опис власними словами з посиланнями `Файл.cs:рядок` на джерело.
Поведінку редактора ще треба звірити з самою грою на справжніх файлах.

| Файл | Що описує | Перевірка скептиком |
|---|---|---|
| [map.md](map.md) | `lightmap1-4.tbl` (квадродерево, ID провінцій, відтінки), `boundbox.tbl`, `colorscales.csv`, `Map_<N>` у DH | ще ні |
| [provinces-config.md](provinces-config.md) | `db/province.csv` (усі 56 колонок), локалізація `config/*.csv`, визначення типу гри, моди, лексери | ще ні |
| [scenario.md](scenario.md) | `.eug`/`.inc`, ключі країн, провінцій, юнітів, дати | ще ні |
| [units.md](units.md) | `db/units/**`, назви юнітів, моделей, корпусів | ще ні |
