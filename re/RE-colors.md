# RE — Точна модель кольору політичної карти (паспорт кольорів)

> Статус: **ПІДТВЕРДЖЕНО живою грою** (2026-10-24, Wine, сценарій 1933 за Польщу).
> Об'єкти: палітра `0x00A44C34`, LUT `0x00AA41CB`, генератор `FUN_004d7db0`,
> читач `FUN_004dc010`; поля провінцій `+0x13E` (off) та `+0x142` (scale).

## 1. Формула (джерело істини — жива пам'ять гри)

```text
колір_пікселя = palette565[ (LUT[light − off] << 6) | scale ]
```

де:
- `light` — 6-бітне значення освітлення пікселя з lightmap (0..63; значення
  19/24 типові для океану — див. re/RE-lightmap.md §6.2);
- `off` — поле провінції `+0x13E` (у грі стабільно 15);
- `scale` — поле провінції `+0x142` — індекс колірної шкали (0..63);
- `LUT` — таблиця `0xAA41CB` (256 Б): `LUT[i] = clamp(i + 47, 4, 127)`
  (для від'ємних i — насичення знизу: i=-64..-1 → 4..46);
- `palette565` — палітра `0xA44C34`: 8192 × u16 LE (RGB565),
  індекс = `(рівень << 6) | шкала` — таким чином 128 рівнів × 64 шкали,
  рядок = LUT-значення (4..127), стовпець = шкала провінції.

Код-джерело: `decomp/004dc010_FUN_004dc010.c` (рядок 77):
`uVar9 = (LUT[(param_4 >> 0x10) - iVar7] << 6) | (iVar2 * 2 >> 1);`
де `iVar7 = *(int*)(prov + 0x13E)`, `iVar2 = *(int*)(prov + 0x142)`,
`param_4 >> 0x10` = light пікселя (16.16 фіксована точка).

## 2. Палітра

- Адреса `0x00A44C34`, розмір 16384 Б = 8192 × u16 LE.
- **Генерується в runtime** (не в файлі): у меню таблиця нульова; заповнюється
  при першому рендері карти (після входу в сценарій).
- Генератор: `FUN_004d7db0` (`decomp/004d7db0.c`) — 256 шкал × 3 сегменти;
  вихідні шкали — кеш `0xA43018` (256 записів × 14 Б).
- Другий буфер-близнюк: `0xA44C74` (той самий генератор записує в обидва).
- Контрольні записи (дамп живого сценарію 1933):
  - океан: шкала **12**, рядки LUT 47-49 → `(136, 172, 216)` = 0x8D7B;
  - Польща: шкала **8** — LUT 51 → `(184, 172, 112)`;
  - Англія: шкала **48** (Лондон, провінція 19); Франція: шкала **44** (Париж, 56);
  - СРСР: шкала **53** (Москва 572, Ленінград 553, …).

## 3. LUT (0xAA41CB)

- Розмір 256 Б; знімався з контекстом від'ємних індексів:
  `LUT[i] = clamp(i + 47, 4, 127)`.
- `LUT[0] = 47`, `LUT[80..] = 127` (насичення), `LUT[-64..-43] = 4` (насичення знизу).

## 4. Поля провінцій (base 0x0B770024, запис 0x4B2 Б)

| зсув | тип | сенс | у грі |
|---|---|---|---|
| +0x13E | int | off — зсув освітлення | 15 (стабільно) |
| +0x142 | int | scale — колірна шкала | 0..63 (8=Польща, 12=вода, 44=Франція, 48=Англія, 53=СРСР) |

Морські провінції мають службове значення `scale=55` (607 записів) — це
**категорія «море»**, а не колір: води рендеряться шкалою 12.
