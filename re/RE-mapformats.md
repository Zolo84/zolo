# Бінарні формати мапи (Map_1) — попередній розбір структур

Джерело: файли `map/Map_1/` оригінальної гри. Кількість провінцій: 2771 у Province.csv,
2769 «прочитаних» за логом (airdist).

## Ключові співвідношення розмірів (розраховано)

| Файл | Розмір | Гіпотеза структури |
|---|---|---|
| `boundbox.tbl` | 44 320 = 16 × 2770 | 16 байт/провінцію: **2 пари (x1,y1,x2,y2) = bounding box** у пікселях мапи. Перші uint32: 29952, 11520 → **розмір всієї мапи 29952×11520 пікселів**; далі пари координат (12986,636),(13194,824)... — bounding box провінції 1, провінції 2, ... |
| `airdist.tbl` | 7 664 594 ≈ 2768×2769 | **Матриця попарних повітряних відстаней**: uint32 на пару (N×N без діагоналі). Значення ~48 564 945 — це квадрат відстані або фіксована-точка/множник |
| `navaldist2.tbl` | 7 617 604 ≈ 2751×2769 | Та сама матриця для **морських** шляхів (не всі провінції морські → менше рядків) |
| `adjacent.tbl` | 200 096 | Списки суміжності: 200096/2771 ≈ 72 байти/провінцію; перші значення 0,0,2,3,6,7,9,14 → **CSR-стиль**: масив зсувів (offset) у 3-й масив + самі ID суміжних. 0,2,3,6,7,9,14 — префіксні суми довжин списків |
| `index.tbl` | 1 347 840 ≈ 486×2771 | Індекс тайлів або регіонів для кожної провінції (486 uint32/провінцію?) |
| `lightmap1..4.tbl` | 23.9МБ/20.4МБ/12.2МБ/3.5МБ | Шари освітлення: починаються з 0,6,12,18,24 → масив з 6-байтових записів (LUT?), 23 850 723/6 ≈ 3 975 120 записів ≈ 29952×11520/86 ≈ піксельна карта в 6-байтних пакетах |
| `tiles.bmp` | 11.5 МБ, 8192×1408, палітровий (P) | **Атлас тайлів місцевості**: 8192/64=128, 1408/64=22 → 2816 тайлів 64×64 (або інша сітка) з палітрою |

## Province.csv — головна таблиця провінцій (2771 рядків)
Колонки: Id;Name;Area;Region;Continent;Climate;Terrain;SizeModifier;AirCapacity;
Infrastructure;City;Beaches;Port Allowed;Port Seazone;IC;Manpower;Oil;Metal;Energy;
Rare Materials; + 8 пар координат (City/Arrmy/Port/Beach/Fort/AA/Counter/Terrain x2 +
Fill coord) — у пікселях 0..14968×5752 (≈ половина від 29952×11520 — UI-масштаб 0.5).

## Що треба дослідити далі (для реалізації власного двигуна)
1. Точний порядок байт і значення airdist (перевірити: sqrt(48564945) ≈ 6969 — схоже на
   «відстань² × масштаб»; при 29952px ширини ε 6969 — це ~2.3k px при кроках 3 — гіпотеза).
2. Формат adjacent.tbl повністю (3 масиви CSR: offset, count?, id).
3. Розкладка tiles.bmp (розмір тайла, кількість, палітра) + зв'язок з lightmap.
4. Як Province.csv координати ставляться до пікселів мапи та tiles.
5. index.tbl — що саме індексується (тайли? полігони провінцій?).
6. Формат scripted «map/adj-defs.csv» (водні протоки/канали) і distances.csv.

Ці 6 пунктів — єдиний великий недосліджений блок: уся 2D-геометрія світу.
