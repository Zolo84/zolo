1. **Обробник 0x16** — знайдено повний конвеєр і головного споживача (сцена гри `0x64c3b0` → `0x65fab0`: PgUp/PgDn, Home, F10-F12, цифрові хоткеї, значення 5); **обробника Pause (0x13) та ± (0x2b/0x2d) у .text НЕМАЄ**; маршрут "клавіші → d13360+0x14" мертвий (d13360 завжди NULL). Механізм паузи — у невідкомпільованому коді **[НЕВСТАНОВЛЕНЕ]**.
2. **Декремент автосейву — ЗНАЙДЕНО**: подія місяця 0x19 (з 0x42cf30) → case 0x19 у 0x64c3b0 → `[+0x221be]--` (0x64d36e); сейв при ==0 (0x64d163), після сейву + кламп періоду {1,3,5,10,−1} мінус 1; щокадровий кламп у case 0x1b (0x64d407). Одиниці — місяці. Попередній звіт помилявся: декремент є (Ghidra злив його у "default").
3. **Швидкість 0 = пауза — НІ**: таблиця 0x83b050 читається лише в 0x42ccc0 і лише для MP (дільник); індекс 0 = 500 (уповільнення), не пауза; стану "paused" немає; SP-темп у зкомпільованому коді від швидкості не залежить **[НЕВСТАНОВЛЕНЕ — справжній регулятор у невідкомпільованому коді]**.
